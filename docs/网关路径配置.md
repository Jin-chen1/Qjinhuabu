# 本机网关路径

豆包适配器优先使用源码仓库中的 `extras/gateway/` 作为网关项目目录；本机已有旧安装且仓库中没有该目录时，继续兼容个人桌面的 `电商工作台/doubao-work-api/`。

网关项目目录用于计算 macOS 钥匙串服务标识。它必须与网关启动时的项目目录一致，不能只移动源码后继续复用旧路径的授权记录。

自定义安装路径时，在启动后端前设置：

```bash
export QJIN_DOUBAO_GATEWAY_PROJECT="/实际安装目录/Qjinhuabu/extras/gateway"
uv run novelvideo api --host 127.0.0.1 --port 8780
```

网关端口保持 `8791`。该环境变量是目录配置，不是凭据；授权仍由本机网关和钥匙串管理。
