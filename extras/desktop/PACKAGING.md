# Q 金 macOS 打包

目标：将当前 Q 金代码快照打包为可双击启动的 Apple Silicon macOS 应用，并交付同一快照源码 ZIP。

运行方式：Electron 45.2.3 承载现有前端；内置 Python 3.12.15、已安装的后端依赖、FFmpeg/FFprobe、Node 和专用 Codex 0.164.0。后端直接提供生产前端，默认使用 18780 端口，端口占用时选择后续可用端口。

数据保存在 `~/Library/Application Support/QJin/desktop/data/`，与应用包分开。现有开发项目保留在原目录，源码和应用不携带私人项目数据、媒体、环境密钥或授权凭据。后端继承环境使用白名单，禁用自动加载外部 `.env`。

豆包工作适配使用 8791。本机已有原适配目录时复用其钥匙串身份；新电脑将适配代码安装到桌面应用的稳定数据目录，再由本人配置和授权。应用移动位置不改变新电脑的授权身份。退出只关闭本应用启动的进程。

执行步骤：

1. 固定前后端和适配源码快照，保留当前未提交功能修复。
2. 验证端口占用、环境隔离和子进程退出行为。
3. 构建生产前端，复制运行依赖并生成应用图标和 `.app`。
4. 校验清单和源码 SHA-256，生成对应源码 ZIP。
5. 启动最终应用，核对首页、项目 API、媒体工具以及退出后进程清理。

没有 Apple Developer 分发证书；本地进行 ad-hoc 签名，尚未公证。此版本面向 macOS 13 及以上的 Apple Silicon Mac。
