# 附加组件来源与边界

更新日期：2026-11-16。本目录提供桌面封装、画布技能与本机网关的配套源码，不包含用户数据或授权凭据。主项目许可证见根目录 `LICENSE`；各组件保留自己的许可证及来源声明，不能将根许可证解释为覆盖所有第三方组件。

## 组件来源

- `desktop/`：Q金 macOS 桌面封装源码，源自 2026-11-10 的 2.1.1 桌面源码快照。包含启动器、打包脚本、依赖清单、测试与图标，不包含整包应用及内置运行环境。
- `canvas-skills/viral-video-oneclick/`：参考视频换商品的 Q金画布适配版，版本 1.1.0，最低 DramaClaw 1.1.2。包含技能正文、原生 Skill Bundle 与使用说明。许可证标记为 Proprietary；本次发布已取得用户授权，不因此改变组件许可证。
- `gateway/`：豆包工作本机网关的白名单源码，包括接口、测试、依赖清单、OpenAPI、部署说明与启动配置脚本。配置和授权由安装者本人完成，不携带原机器登录状态。
- `候选清单.json` 与 `gateway/刷新名单.json`：记录纳入文件、来源别名、大小、SHA-256 与发布副本修改情况，供核对源码来源。

画布配方 ID：`viral-video-intake`、`viral-video-transcript`、`viral-video-segments`、`viral-video-render`、`viral-video-review`、`viral-video-delivery`。

## 桌面历史快照边界

桌面组件是历史快照，不代表最新网页源码已重新打包。发布副本的 `desktop/main.cjs` 已移除旧工作区自动复用逻辑，默认使用应用自己的数据目录，保留显式配置项；这些候选修改未完成桌面运行验收。原历史应用与运行服务未修改。

网页 QK 星云图与桌面历史图标分别保留；新桌面构建前仍须核对图标一致性。新电脑配置、本人授权、真实生成、媒体工具、签名与分发均须分别验收，不能以源码同步或离线测试代替。

## 数据与安全边界

不纳入私人画布、素材、项目和任务数据、`state/`、`runtime/`、`output/`、数据库、浏览器配置、`node_modules/`、虚拟环境、私人 `.env`、授权凭据、历史验证记录或生成演示视频。

本机网关默认仅供本人回环访问。测试凭据为人工夹具；实际授权由安装者配置。文本秘密扫描不能证明二进制图标已经完成 OCR 或元数据隐私鉴定，也不能替代本人授权与端到端验收。

部署步骤与当前验收边界见 `../docs/本地部署.md`。
