# Q金画布

Q金的画布创作工作台源码，包含网页前端、Python 后端，以及本机豆包工作接入、桌面壳和画布技能的补充源码。

本次导入保留本仓库的初始提交历史；上游许可证、NOTICE 和第三方声明一并保留。初始占位说明见 `docs/target-initial-README.md`。

## 源码目录

| 路径 | 内容 |
| --- | --- |
| `frontend/` | 画布、素材库、脚本、生成与恢复界面 |
| `src/novelvideo/` | 接口、任务执行、媒体处理与生成适配器 |
| `tests/` | 后端测试 |
| `extras/gateway/` | 本机豆包工作网关源码与授权入口 |
| `extras/desktop/` | 桌面壳源码候选及版本说明 |
| `extras/canvas-skills/` | 爆款复刻技能与六个 Recipes |
| `docs/本地部署.md` | 本地运行步骤和依赖说明 |
| `extras/README.md` | 补充源码来源及已知边界 |

## 当前功能

- 原视频首帧与完整音轨提取。
- 原片分析、新商品首帧重建和执行脚本生成。
- 视频按完整脚本生成，随后自动合成原音轨。
- 工作流中断恢复、过期运行记录维护与并发运行保护。
- 已提交但回执丢失的豆包任务按原消息恢复，避免重复生成。
- 本机授权接入豆包工作，凭据保留在本机。

## 运行与验证

本机豆包接入面向 macOS 社区版。前端开发端口为 `5173`，后端为 `8780`，网关为 `8791`。请先阅读部署说明并完成本机授权；源码仓库不包含任何授权数据、个人任务记录、输入素材或生成成片。

前端生产构建、社区版构建及针对性的类型与恢复测试已经执行。视频生成仍依赖真实授权和上游服务；部署说明中记录补充源码的版本边界。

桌面壳目录是可审阅的历史源码候选，不能将其视为已经重新打包并在新电脑验收的桌面发行版。

GitHub Actions 源文件保留在 `.github/workflow-templates/`，当前未启用自动运行。启用时需使用具有工作流写权限的授权，将模板放回 `.github/workflows/`。
